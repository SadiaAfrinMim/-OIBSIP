# OIBSIP-WebDev-L2-Task-2 — Tribute Page

Last updated: 2026-08-05

A responsive tribute page created for the OIBSIP Web Development Level 2 coursework (Task 2).

## Overview

This repository contains a single-page static site that honors a notable individual. The page demonstrates semantic HTML, responsive layout, and basic styling.

## Project structure

- `index.html` — main HTML file
- `css/styles.css` — stylesheet
- `assets/` — images and other media

## How to view

1. Open the project folder.
2. Open `index.html` in a web browser (or use Live Server in VS Code).

## Technologies

- HTML5
- CSS3

## Notes

- Replace placeholder content and images in `assets/` as needed.
- Tested in modern browsers (Chrome, Firefox, Edge).
