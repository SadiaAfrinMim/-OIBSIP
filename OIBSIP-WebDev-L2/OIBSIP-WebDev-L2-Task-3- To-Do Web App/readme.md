# OIBSIP-WebDev-L2-Task-3 — To-Do Web App

Last updated: 2026-08-05

A simple, responsive To-Do web application built for the OIBSIP Web Development Level 2 coursework (Task 3).

## Overview

This project provides a small single-page app to add, edit, complete, and remove tasks. It demonstrates DOM manipulation, event handling, and basic persistence using localStorage.

## Features

- Add new tasks
- Mark tasks as completed
- Edit and delete tasks
- Persist tasks in the browser using localStorage
- Responsive layout for desktop and mobile

## Project structure

- `index.html` — main HTML file
- `css/styles.css` — styles
- `js/app.js` — application logic
- `assets/` — optional images or icons

## How to run

1. Open the project folder.
2. Open `index.html` in a web browser, or serve it with a static server / Live Server in VS Code.

Optional: run a simple static server using Python:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## Notes

- Replace placeholder content and styles as needed.
- The app stores tasks locally in the browser; clearing the browser data will remove tasks.
